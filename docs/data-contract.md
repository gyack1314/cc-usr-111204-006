# 寄存器服务约定

地址均为零基，ReadHolding对应功能03、ReadInput对应04，不提供写方法。words为0到65535整数列表，适配器返回异常时含exception字段而无可用words；不把exception字节解成正常值。allowed_ranges是含端点地址段，计划不得越段。

byte_order作用于每个16位字的字节，word_order作用于整个多字字段的字顺序，先形成约定的规范字节再解释类型。字段类型为uint16/int16/uint32/int32/float32/bits，位段只允许一个字。scale/offset为精确分数，IEEE特殊值依字段策略保留或诊断，不伪装成零。

generation为设备独立维护的16位计数，奇数更新中、偶数稳定；完整回绕最小时长是设备保证，采样时间严格更短才可利用相等偶数判据，不对任意设备计数器自动推导此保证。所有块失败都使该组不被正式接受。

domain只数映射字数，不规划、轮询或解码。
